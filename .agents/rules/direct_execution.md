# Direct Execution Directive

- **No Planning Mode / No Approval Halts**: Do not enter planning mode, do not create `implementation_plan.md` artifacts asking for user confirmation, and do not pause for user approval before writing code, editing files, or running commands.
- **Immediate Action**: Proceed directly to implementation and execution for all tasks immediately.
- **Summary & Verification**: Execute all necessary edits, run tests/builds, and present the completed results and verification directly to the user.
